# LASIKA — Swiss Luxury Timepieces

A premium luxury watch e-commerce landing page built with Next.js 16, React 19, Framer Motion, GSAP, and Tailwind CSS v4.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Next.js 16.2.6** — React Framework
- **React 19.2.4** — UI Library
- **Tailwind CSS v4** — Utility-First CSS
- **Framer Motion 12** — Scroll Animations & Micro-Interactions
- **GSAP 3** — ScrollTrigger & Timeline Animations
- **Lucide React** — Icon Library
- **Playfair Display** — Luxury Serif Typography
- **Geist** — Clean Sans-Serif Body Font

## Sections

1. **Hero** — Animated watch entrance with parallax scroll
2. **Product Showcase** — Carousel with floating spec labels
3. **Watch Detail** — GSAP-powered callout annotations
4. **Watch Box Reveal** — Cinematic box docking animation
5. **Reviews** — Premium testimonial carousel with trust badges
6. **FAQ** — Animated accordion with glass morphism

## Build

```bash
npm run build
npm start
```
